## 一、导航地图：先搞清楚自己要什么

"科学上网"这个需求背后，其实对应着完全不同的使用场景。选错方案是体验差的第一大原因。先回答三个问题：

1. **你要访问什么？**（Google/YouTube/Netflix/海外游戏/国内平台回国）
2. **你有多大的流量需求？**（偶尔查资料 vs 每天看视频）
3. **你愿意投入多少时间维护？**（开箱即用 vs 动手折腾）

三个问题的答案组合，基本决定了你适合哪条路线：

| 你的画像 | 推荐路线 |
|----------|----------|
| 新手、轻度使用、怕折腾 | 机场（订阅代理） |
| 公司办公、需要固定 IP、隐私敏感 | 信誉 VPN 或自建 |
| 技术用户、追求可控与隐私 | 自建 VPS |
| 重度用户、怕单点故障 | 机场 + 自建双保险 |

## 二、两大方案深度对比

VPN 与机场是两条主流路线，本导航站对它们的定位如下：

| 对比维度 | 机场（订阅代理） | 商业 VPN |
|----------|------------------|----------|
| 节点数量 | 数十至上百个，覆盖广 | 通常数十个，按国家分布 |
| 线路质量 | 针对跨境链路优化（IEPL/CN2） | 通用优化 |
| 协议 | SS/Trojan/VLESS/Hysteria2 等 | 多为自有协议（WireGuard/OpenVPN 系） |
| 客户端 | 通用客户端（Clash 等） | 厂商专用 App |
| 计费 | 按流量/套餐 | 通常按月不限量 |
| 隐私政策 | 参差不齐，需甄别 | 大厂较规范，有审计报告 |
| 上手难度 | 需要导入订阅，略有门槛 | 下载即用 |
| 适用地区 | 大中华区用户为主 | 全球用户 |

**一句话总结**：

- 人在国内要访问海外 → 机场（线路优化是核心优势）；
- 人在海外要访问国内 → 机场回国线路或自建中转；
- 人在海外要隐私保护 → 商业 VPN 或自建；
- 公司远程办公 → 公司提供的 VPN（勿用个人方案）。

## 三、VPN 方案详解

## 三、VPN 方案详解

### 3.1 商业 VPN 的适用场景

- **公共 Wi-Fi 防护**：咖啡馆、机场等公共网络环境下保护流量不被窃听；
- **跨国旅行**：访问国内服务或保持海外网络隐私；
- **流媒体地区限制**：切换地区观看不同区域内容（如美国 Netflix vs 日本 Disney+）；
- **企业远程办公**：安全接入公司内网资源；
- **数据完整性保护**：防止 ISP 对特定协议限速（如对 BitTorrent 的限速）。

### 3.2 选择商业 VPN 的要点

| 要点 | 说明 | 如何验证 |
|------|------|----------|
| 无日志政策 | 是否经过第三方审计（如 Deloitte、Cure53） | 查看官网审计报告 |
| 协议支持 | WireGuard 优先，性能与安全平衡最好 | 确认支持 WireGuard 或自有协议 |
| 服务器覆盖 | 目标地区是否有足够节点 | 查官网节点列表 |
| 速度 | 参考第三方评测（如安全机构实测） | 阅读独立评测 |
| 同时在线设备 | 常见 5-10 台 | 套餐说明 |
| 退款政策 | 30 天退款是主流 | 购买前确认条款 |
| 客服 | 24/7 在线支持 | 发工单测试响应速度 |

### 3.3 免费 VPN 的坑

免费 VPN 的商业模式决定了它必然通过某种方式变现：

- **用流量换免费**：免费服务常靠出售用户数据盈利，研究表明超过 75% 的免费 VPN 应用包含追踪器；
- **速度无保障**：免费节点拥挤，实际带宽往往只有几十 Kbps；
- **安全隐患**：部分免费 VPN 被曝植入广告、追踪器甚至恶意软件；
- **功能阉割**：限制协议、限制流量，引导用户付费升级。

**结论**：对隐私和安全有要求时，不要使用免费 VPN。付费大厂（ExpressVPN、NordVPN、ProtonVPN 等）有第三方审计记录，功能完整。

## 四、机场方案详解

## 四、机场方案详解

### 4.1 机场适合谁

- 需要稳定访问 Google、GitHub、海外 SaaS 的跨境用户；
- 需要看 YouTube、Netflix 等流媒体的用户；
- 对线路质量要求高、接受一定学习成本的用户；
- 月流量需求在 100G 以上的重度用户（相比 VPN 月付套餐性价比更高）。

### 4.2 机场核心指标详解

| 指标 | 解释 | 怎么验证 |
|------|------|----------|
| 线路 | IEPL/IPLC > CN2 GIA > CN2 GT > 普通 BGP | 看线路公示与测速 |
| 协议 | Trojan/VLESS/Hysteria2 是否支持 | 看套餐说明 |
| 稳定性 | 运营时长、节点在线率 | 看状态页与口碑 |
| 设备数 | 同时在线设备限制 | 看套餐条款 |
| 流量规则 | 重置周期、超额处理 | 看套餐说明 |
| 售后 | 工单/群组响应 | 实测提问 |

### 4.3 套餐类型一览

| 类型 | 适合人群 | 典型价格区间 |
|------|----------|-------------|
| 月付试用 | 新用户尝鲜 | 10-30 元/月 |
| 年付入门 | 轻度用户 | 100-300 元/年 |
| 年付中端 | 重度用户（YouTube + 下载） | 300-600 元/年 |
| 专线旗舰 | 商务/游戏/直播 | 600-2000 元/年 |

### 4.4 机场使用基本流程

1. 选择套餐并购买，获取订阅链接；
2. 下载客户端（Clash Verge Rev / Shadowrocket / v2rayN）；
3. 导入订阅，更新节点列表；
4. 选择节点，开启规则模式；
5. 验证连通，开始使用。

### 4.5 常见套餐陷阱

- **月流量虚标**：宣传 500G 实际高峰限速至 10Mbps；
- **设备数陷阱**：不限设备但限制 IP 数，实际上限制更严；
- **新户优惠后涨价**：首月极便宜，次月恢复正常价，购买前确认续费价格；
- **退款难**：声称 7 天退款但工单不响应，购买前确认退款政策。

## 五、自建方案：VPS + 一键脚本

### 5.1 自建的优势与代价

| 优势 | 代价 |
|------|------|
| 完全自主可控 | 需要 Linux 基础 |
| 隐私性最强 | 需维护系统安全 |
| 无跑路风险 | 单点故障需自行处理 |
| 可自定义线路与协议 | 需自行购买 VPS |

### 5.2 推荐部署方式

**Xray + 面板（推荐新手）**：

```bash
# 3x-ui 一键安装
bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh)
```

**Docker 部署（推荐干净环境）**：

```bash
docker run -d --restart=always \
  -e PANEL_APP_PORT_HTTP=8080 \
  -v /etc/x-ui:/etc/x-ui \
  --network=host \
  --name x-ui ghcr.io/x-ui/x-ui:latest
```

### 5.3 自建注意事项

- 选择线路好的 VPS 商（参考社区评测）；
- 开启防火墙，仅放行必要端口；
- 定期更新系统与内核；
- 使用域名 + CDN 前置可提升隐蔽性（进阶）；
- 建议搭配"仅代理必要流量"的分流策略。

### 5.4 VPS 供应商横向对比

| 供应商 | 推荐地区 | 线路 | 价格区间 | 特点 |
|--------|----------|------|----------|------|
| 搬瓦工 | HK/KVM | CN2 GIA | $50-100/年 | 稳定、口碑好、付款方式多 |
| hostdare | CN2 GIA | 美西 | $30-60/年 | 性价比高、线路优化 |
| DMIT | HK/CN2 | Premium | $50-120/年 | 大带宽、晚高峰稳定 |
| RackNerd | 美西 | 普通BGP | $15-40/年 | 便宜、适合入门练手 |
| CloudCone | 美西 | 普通BGP | $15-50/年 | 按小时计费、灵活 |
| DediPath | 美西 | CN2 GT | $30-60/年 | 大带宽 |

**选机建议**：预算充足 → 搬瓦工 CN2 GIA 或 DMIT；预算有限练手 → RackNerd；重度大流量用户 → DediPath。

| 客户端 | 平台 | 开源 | 特点 | 适合人群 |

### 6.2 浏览器扩展推荐

- **SwitchyOmega**（Chrome/Firefox）：配合代理使用，支持自动切换规则，灵活度高；
- **uBlock Origin**：广告屏蔽，减少无效流量消耗，提升页面加载速度；
- **Privacy Badger**：追踪保护，阻止第三方追踪器；
- **HTTPS Everywhere**：强制 HTTPS 连接，提升连接安全性（注意部分机场节点 HTTPS 证书兼容性）。

### 6.3 手机端特别提示

- **iOS**：Shadowrocket / Stash 是主流；国区 App Store 可能下架，建议注册外区账号下载；
- **Android**：Clash Meta for Android / Mihomo Party / v2rayNG 均可；国产 ROM 注意权限管理；
- **省电设置**：部分 Android 系统的后台省电策略可能影响代理连接，建议将代理客户端加入白名单。

## 七、配套工具与资源

### 7.1 订阅管理工具

- **subconverter**：开源订阅格式转换工具，支持 Docker 一键部署；本地运行，不泄露节点信息；
- **sub-store**：订阅聚合管理工具，支持多订阅源、定时同步、脚本控制；
- **Clash Verge 内置**：直接支持订阅 URL 更新，无需第三方工具。

### 7.2 网络诊断工具

| 工具 | 用途 | 使用场景 |
|------|------|----------|
| ping | 检测节点连通性 | 快速判断节点是否可达 |
| mtr | 路由追踪 + 丢包率 | 定位跨境链路问题 |
| traceroute | 显示路由路径 | 判断网络瓶颈在哪一跳 |
| iperf3 | 带宽测试 | 精确测量节点上下行速度 |
| dig / nslookup | DNS 解析测试 | 排查 DNS 泄漏问题 |
| Speedtest CLI | 综合网速测试 | 多时段对比验证 |
| WireShark | 抓包分析 | 进阶调试（需一定网络基础） |

### 7.3 常见故障快速修复

| 症状 | 原因 | 解决方案 |
|------|------|----------|
| 节点连接超时 | 节点被封锁或网络问题 | 切换其他节点 |
| 连接成功但无法上网 | DNS 污染或代理端口问题 | 开启客户端 DNS 保护 |
| 速度时快时慢 | 线路拥塞或节点不稳定 | 换专线节点或 Hysteria2 |
| 订阅更新失败 | 链接过期或防盗链 | 面板重新生成订阅链接 |
| 设备被踢下线 | 超过同时在线设备数 | 面板查看并移除闲置设备 |
| YouTube 画质低 | 带宽不足或节点限速 | 选择高带宽节点 |
| Netflix 检测到代理 | 节点 IP 被识别 | 切换流媒体解锁节点 |

## 八、按场景选择路线图

### 场景 A：留学/出差在海外，要回国看视频

- **问题本质**：需要访问国内平台（爱奇艺、腾讯视频、B站等）但物理位置在海外。
- **推荐方案**：机场回国线路（中转国内入口）或自建国内中转。
- **选线要点**：优先选"回国线路"标注的节点（这些节点专门优化了从海外到国内的访问）；关注晚高峰表现（下班后海外回国流量也大）。
- **备选方案**：部分国内平台提供海外版（YouTube 上传的内容无需代理），可优先尝试。
- **注意事项**：回国线路通常价格更高或流量更少；某些平台检测严格，需使用原生 IP 节点。

### 场景 B：国内用户，日常查资料 + YouTube

- **问题本质**：需要稳定访问海外服务，主要用于学习和工作而非娱乐。
- **推荐方案**：中端机场（200G/月左右套餐），线路选 CN2 GIA 或 IEPL 专线。
- **选线要点**：关注流媒体解锁（YouTube 1080P+ 需要稳定带宽）；优先选香港、日本节点延迟最低；CN2 GIA 节点晚高峰基本不降速。
- **备选方案**：预算充足可叠加自建 VPS 作为备用线路，重要时刻有保障。

### 场景 C：游戏玩家

- **问题本质**：需要低延迟、低丢包的跨境连接，游戏对网络质量要求极高。
- **推荐方案**：提供游戏专线的机场，优先选 IEPL/IPLC 专线节点（延迟 < 80ms 体验才好）。
- **关注指标**：丢包率（< 1% 才算好）比带宽更重要；延迟测试结果应选延迟最低且抖动小的节点。
- **备选方案**：使用游戏加速器（针对特定游戏线路优化，但通常只覆盖少数游戏）。
- **使用建议**：不要用全局代理玩国服游戏（会被识别为海外 IP）；建议规则模式将国服直连。海外服游戏走代理。

### 场景 D：注重隐私的技术用户

- **问题本质**：需要最强的隐私保护，不信任第三方服务商。
- **推荐方案**：自建 VPS（VLESS + Reality 或 WireGuard），完全自主可控。
- **隐私优势**：日志只有你自己掌握；无第三方可见流量；可自定义加密方式。
- **备选方案**：无日志商业 VPN（如 Mullvad、ProtonVPN），经过独立审计，有退款保障。

### 场景 E：企业远程办公

- **问题本质**：需要安全可靠的方式访问公司内网资源，与个人使用场景完全不同。
- **推荐方案**：使用公司统一部署的 VPN 方案（这是公司 IT 提供给员工的办公工具）。
- **注意**：不要将公司 VPN 与个人代理混用，避免合规风险；公司 VPN 通常有专用客户端，与个人代理工具独立使用。
- **例外**：如果公司允许使用个人设备接入，需要确保个人代理工具已完全关闭，避免公司网络流量经过个人代理节点。

### 8.5 本导航站使用建议

首次使用本导航站时，建议按以下顺序阅读：

1. **先对照第一节的场景图**：明确自己属于哪类用户；
2. **再读第二节方案对比**：了解 VPN 与机场的本质区别；
3. **然后按场景选择路线图**：找到最适合自己的方案组合；
4. **最后看上手指南**：三步完成配置，快速验证效果。

| 解锁 | 节点可访问被地理限制的内容 |
| 伪装 | 将代理流量伪装成 HTTPS 流量 |
| TUN | 虚拟网卡，接管全部流量 |
| 分流 | 按规则决定哪些流量走代理 |

## 十、常见问题

**Q1：机场和 VPN 哪个更安全？**
A：两者都提供加密隧道，安全性取决于服务商的信誉与日志政策。正规机场与知名 VPN 的安全级别相当，关键看运营方是否可信、是否记录日志。自建节点隐私性最强。

**Q2：用代理会违法吗？**
A：不同国家/地区法律规定不同，请务必了解并遵守所在地法律。本仓库所有内容仅供技术学习与合法用途参考，作者不对使用结果负责。

**Q3：为什么晚上特别卡？**
A：晚高峰跨境线路普遍拥堵，IEPL 专线能缓解但无法完全消除。切换专线节点、改用 Hysteria2 协议、错峰使用大流量任务均可改善。

**Q4：代理流量会被监控吗？**
A：理论上流量经过节点服务器，运营商可能记录元数据（IP、连接时间、流量大小）。敏感操作建议使用自建节点，并开启客户端 DNS 保护防止 DNS 泄漏。

**Q5：换设备后配置要重来吗？**
A：重新导入订阅即可，无需重复配置。注意套餐设备数限制，及时在面板清理闲置设备。

**Q6：自建 VPS 需要什么配置？**
A：纯代理用途 1 核 512MB 起步即可；同时跑面板与测速建议 1 核 1GB。线路质量远比配置重要，优先选择口碑好的 VPS 商。

**Q7：怎么测速最准？**
A：多时段多次测速取平均，晚高峰结果最有参考价值；用真实场景（YouTube 加载速度、Netflix 画质）验证体验。

**Q8：订阅链接泄露了怎么办？**
A：立即在机场面板重置订阅链接，检查设备列表是否有异常设备，及时踢掉未知设备。

**Q9：为什么同一个节点白天快晚上慢？**
A：这是跨境线路的天然特性，与国内运营商的国际出口带宽有关。专线（IEPL/IPLC）可以大幅缓解，但无法完全消除。选择晚高峰表现稳定的节点是关键。

**Q10：买完发现不好用能退款吗？**
A：取决于机场政策。正规机场通常有 24-72 小时退款窗口，少数提供按比例退款。建议先月付体验满意后再购买年付套餐。

**Q11：套餐性价比怎么算？**
A：不能只看总价，要计算实际可用流量。示例：套餐A年付200元标称200G但晚高峰限速10Mbps，实际有效流量约100G，月均成本0.17元/GB；套餐B年付300元标称400G且不限速，实际有效流量约380G，月均成本0.07元/GB。套餐B实际性价比更高。

**Q12：可以用支付宝/微信支付吗？**
A：大多数机场支持加密货币（USDT/TRC20 最常见）、支付宝、微信支付。部分机场仅支持加密货币。建议优先选择有加密货币支付的服务商，隐私性更强。

**Q13：什么情况下需要同时用机场和 VPN？**
A：场景一：企业用户需要在访问公司内网的同时访问海外资源（VPN 负责内网，机场负责海外）。场景二：需要同时访问两个不同地区的内容（如同时看美区 Netflix 和国内爱奇艺）。场景三：测试同一网站在不同地区的表现（两个客户端分别走不同出口）。
